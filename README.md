# Hi, I’m Salvo 👋

I’m Salvatore Scaravalle, a software engineer. On GitHub I go by **salvoZero4**.

I like building software around everyday problems: keeping track of what I lifted last week, finding people to study with on campus, or figuring out what’s happening in town. These projects give me a reason to work on both the screens people use and the systems behind them.

## A few things I’ve built

- **[ZeroBuff](https://github.com/salvoZero4/ZeroBuff)** — An open source workout tracker for iOS and Android. Plan your week, log each set, and see what you lifted last time without digging through notes.
- **[Huddle](https://github.com/salvoZero4/Huddle)** — An iOS app my team built at the University of Palermo to help students find and create study groups on campus. Built with SwiftUI.
- **[Benessere in Rete](https://github.com/salvoZero4/bando-benessere-in-rete)** — A web prototype for discovering local associations, public services, and events. The project won a grant from the Municipality of Altavilla Milicia.
- **[AFAM Digital Identity System](https://github.com/salvoZero4/AFAM-Digital-Identity-System)** — A JavaFX desktop app for digital identities and portfolios. This is where I worked through the whole process, from requirements and system design to implementation and testing.
